# 推送通知
### 1. 开工前，先拉最新代码
git pull
### 2. 写你的代码...
### 3. 提交
git add .
git commit -m "具体改了啥"
### 4. 推送前再拉一次，防止对方刚推了新东西
git pull
### 5. 推送
git push
如果 git pull 提示冲突，就打开冲突文件，把 <<<<<<<、=======、>>>>>>> 这些标记删掉，保留正确代码，然后：
bash
git add .
git commit -m "解决冲突"
git push
### 6.三条约定就够了
改之前说一声：微信/群里说“我改登录模块”，避免两个人同时改同一个文件。
每天先 pull：别攒一周才拉代码。
别用 git push -f：强推会把对方代码冲掉
### 7.代码直接推到main分支就行了,如果你想安全一点可以自行创建新分支
